One absurd invention pitch, 122 characters, one sentence:

> A jar lid that only loosens the moment you hand it to someone stronger, so you can keep taking full credit for opening it.

The joke: the lid automates the universal experience of a stuck jar that
only opens once a second pair of hands takes it — and the real invention
is not the loosening, it is letting you keep the credit.

## Run it

```sh
python3 main.py
```

Writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`),
byte-identical on every run. Python 3.13, standard library only, no network.
